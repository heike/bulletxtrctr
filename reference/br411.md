# 3d topological surface measurements for one land of a bullet from the Hamby study

A 3d topographic surface map of Land 1 on Bullet 1 of Barrel 4 (Hamby
study 252). The file is stored in x3p format (ISO standard for forensic
measurements).

## Usage

``` r
br411
```

## Format

an x3p object (list) with 5 elements

- header.info:

  list consisting of scan dimensions and scan resolution (in microns per
  pixel)

- surface.matrix:

  2d numeric matrix of the scan heights.

- feature.info:

  list containing scanning details and x3p formatting

- general.info:

  list containing instrumentation details

- matrix.info:

  list of technical details for the matrix encoding
